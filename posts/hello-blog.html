搭建这个静态技术博客

发布于 2026-05-15 · 标签：静态站点 / GitHub

本博客是一个零构建步骤的静态站点：根目录的 index.html 负责首页，assets/style.css 负责样式，assets/app.js 在浏览器中请求 GitHub 公开 API 以列出你的仓库；若网络或 CORS 环境不允许，会回退到脚本里内置的仓库列表。

如何修改文案与头像

编辑 index.html 中「关于」「文章」等段落即可。头像默认使用 GitHub 用户 id 对应的头像 URL，脚本也会在可用时覆盖为 API 返回的最新头像。

如何新增文章

复制 posts/ 下任意一篇 HTML，修改标题与正文，然后在首页 index.html 的「文章」区块增加一条链接。

部署到 GitHub Pages

  1. 将 tech-blog 文件夹推送到任意 GitHub 仓库（可作为仓库根目录或子目录）。
  2. 在仓库 Settings → Pages 中选择分支与目录（若站点在子目录，可使用 GitHub Actions 将 tech-blog 发布到 gh-pages，或把该文件夹内容放到根目录）。
  3. 启用 HTTPS 后，首页即可通过 fetch 正常访问 api.github.com。

若你希望用 Markdown 写作，可以后续接入 Eleventy、Astro 等静态生成器；当前版本刻意保持简单，便于快速上线与改版。
