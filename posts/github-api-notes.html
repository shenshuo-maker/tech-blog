前端拉取 GitHub 公开仓库列表

发布于 2026-05-15 · 标签：GitHub API / JavaScript

GitHub 提供无需鉴权即可访问的 REST 接口，例如列出某用户的公开仓库： 

GET https://api.github.com/users/USERNAME/repos?per_page=100&sort=updated

浏览器端直接 fetch 时，需要页面通过 https: 提供，以便与 API 的安全上下文一致；本地用 file:// 打开时，部分环境可能拦截跨域或混合内容，因此推荐用本地静态服务器或部署后再预览。

排序与展示

API 返回的每条记录包含 pushed_at、updated_at、language、description、topics 等字段。本博客在客户端按推送时间降序排序，让最近有提交的仓库排在前面。

离线回退

在 assets/app.js 中的 FALLBACK_REPOS 保存了一份与当前公开仓库同步的快照。当 API 不可用时，页面仍能展示项目卡片；你只需在新增重要仓库后偶尔更新该数组即可。
